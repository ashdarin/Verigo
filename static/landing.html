常见问题

关于邮箱验证

开始使用前，你可能想了解这些。

什么是邮箱验证？

邮箱验证会结合语法、域名、MX 记录和邮件服务器响应等信号，判断一个地址当前是否可能正常接收邮件。

Verigo 的结果有多准确？

Verigo 提供基于验证时点技术信号的判断。邮件服务器策略、临时故障和账户状态会变化，因此任何服务都无法保证后续邮件一定送达。

什么是 Catch-all？

Catch-all 域名可能接收发往任意前缀的邮件，因此仅凭服务器响应无法确认某个具体邮箱是否真实存在，这类结果应谨慎处理。

Verigo 会向目标邮箱发送邮件吗？

不会发送营销或测试邮件。验证过程会与目标域名的公开 DNS 和邮件服务器交互。

可以批量验证邮箱吗？

可以。你可以上传 CSV 或 Excel，也可以直接粘贴名单进行批量验证，并下载处理结果。

Verigo 提供 API 吗？

提供。你可以创建 API Key，将邮箱验证接入表单、CRM 或内部工具。

上传的邮箱会被保存吗？

系统会为任务执行与结果展示保存必要数据。可下载结果在 30 天后清理，任务记录在 90 天后清理，详情请查看隐私说明。
